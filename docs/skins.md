# 制作新造型

在 `doudou_pet/assets/skins/` 下增加目录，例如 `gardener/`。目录名应为小写英文、数字、下划线或连字符，且与 `id` 相同。为保持落脚点稳定，同一套素材请使用相同的透明画布、脚底基线和像素倍率。

```json
{
  "id": "gardener",
  "name": "园丁豆豆",
  "idle": "idle.png",
  "interact": [
    {"file": "water_1.png", "ms": 180},
    {"file": "water_2.png", "ms": 270}
  ],
  "bubble": "长大啦！"
}
```

文件用 UTF-8 保存，图帧必须是同目录的 PNG。`ms` 是帧停留时间，范围为 20 到 5000；互动列表最多 48 帧，动作结束后自动返回待机。重新运行应用，在衣柜中查看。分享皮肤之前注明图片来源与许可。
